# Pinterest 拼贴元素关键词库

根据用户照片的内容、色调、氛围选择关键词。Pinterest 搜索用**英文**效果最好，可加 `aesthetic`、`collage`、`png`、`transparent` 等后缀提高匹配度。

## 一、按照片主题选关键词

| 照片主题 | 推荐搜索词（任选 2-3 组） |
|---|---|
| 人像 / 自拍 / OOTD | `vintage paper texture`, `aesthetic objects flatlay`, `polaroid frame png`, `coquette room decor`, `film camera png` |
| 美食 / 咖啡 / 烘焙 | `bakery illustration`, `coffee cup png`, `vintage recipe card`, `food collage elements`, `cafe aesthetic` |
| 旅行 / 风景 / 户外 | `vintage map png`, `nature sticker pack`, `travel collage elements`, `mountain illustration`, `washi tape png` |
| 校园 / 学习 / 书桌 | `notebook page texture`, `sheet music png`, `stationery flatlay`, `academic aesthetic`, `book stack png` |
| 居家 / 生活 / 日常 | `vintage trinkets`, `candle png`, `plant illustration`, `cozy room aesthetic`, `fabric swatch` |
| 宠物 / 动物 | `paw print png`, `vintage animal illustration`, `pet collage elements`, `bone sticker` |

## 二、通用拼贴元素（每次必搜 1-2 组）

这些是参考图风格的核心元素，几乎每张拼贴都用得上：

- **纹理背景**：`vintage paper texture`, `old newspaper texture`, `sheet music page`, `handwritten letter png`
- **相框/边框**：`polaroid frame png`, `instant photo frame`, `vintage stamp border`, `tape png transparent`
- **小物件**：`vintage key png`, `safety pin png`, `paper clip png`, `dried flower png`, `butterfly sticker`
- **涂鸦装饰**：`hand drawn arrow png`, `star doodle png`, `scribble underline png`, `sparkle sticker`
- **胶带/贴纸**：`washi tape png`, `sticker pack aesthetic`, `price tag png`, `ticket stub png`

## 三、按色调匹配

| 照片主色调 | 关键词调整 |
|---|---|
| 暖调 / 米色 / 棕 | 加 `warm tone`, `sepia`, `cream aesthetic` |
| 冷调 / 蓝 / 灰 | 加 `cool tone`, `muted blue`, `silver aesthetic` |
| 黑白 / 高对比 | 加 `black and white`, `monochrome collage`, `dark aesthetic` |
| 鲜艳 / 多彩 | 加 `colorful`, `maximalist`, `kitsch collage` |
| 粉色 / 少女 | 加 `coquette`, `pink aesthetic`, `soft girl` |

## 四、搜索技巧

1. **优先搜 png / transparent**：`butterfly png transparent` 比 `butterfly` 更容易得到可直接抠用的元素。
2. **加 aesthetic**：`aesthetic objects` 比 `objects` 结果更有风格感。
3. **一次搜 3-5 组不同关键词**：每组挑 1 张，避免元素同质化。
4. **避开人脸/复杂场景**：拼贴元素选**单品、纹理、小物件**，不要选又一张人物照片（主体已经是用户了）。
5. **图片尺寸**：优先选长边 ≥ 800px 的图，Pinterest 详情页的原图通常够用。
6. **如果 Pinterest 需登录**：按 browser-use-automation-mac 的登录交接规则处理，不要绕过。

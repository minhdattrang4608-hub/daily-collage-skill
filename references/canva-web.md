# Canva / 可画网页 Magic Layers

## 目标与边界

输入为已检查的本地拼贴 PNG/JPEG，输出为同一账号下可打开、已验证独立元素的设计链接。Magic Layers 会用 AI 重建图层，不保证与原始素材一一对应；尤其需要检查人物面部、白边和装饰物。保留原始 PNG 与素材作为对照。

国际版 canva.com 与国内版 canva.cn 的账号和功能不能混同。优先使用用户指定的站点或已打开的相关页面。用户只说“可画”、没有可识别的现有站点时，询问使用国内版还是国际版；不静默换站、换账号或换工作空间。

进入网页前先按 [doubao-canva-mcp.md](doubao-canva-mcp.md) 选择路线。MCP 已提供目标设计或已经上传资产时复用它，从相应步骤继续，避免重复上传。

## 1. 准备与断点

在本次 `collage_work/canva-state.json` 中记录下面字段，随实际进度更新：

```json
{
  "input_file": "/absolute/path/collage_final.png",
  "site": "https://www.canva.com",
  "status": "local_ready",
  "design_url": null,
  "observations": [],
  "blocker": null
}
```

状态可用 `local_ready`、`login_required`、`uploaded`、`processing`、`layers_verified`、`feature_unavailable`、`failed`。观察记录包含实际看到的状态和时间；不写密码、Cookie 或登录令牌。续跑先打开记录的设计，确认当前状态，避免重复上传、重复拆层和消耗额度。

## 2. 选择浏览器和登录

- 使用当前宿主浏览器/电脑操作工具，先读其工具文档，再读取页面结构或截图。
- 优先复用已登录的相关页面。MCP 已授权不代表浏览器也登录。
- 登录、验证码或扫码需要用户参与时，展示当前网页并准确说明需要完成什么。用户完成后重新检查登录状态再继续；跳过时保留断点，不反复请求。
- 不从浏览器数据库读取凭证，不调用未公开的拆层服务。

## 3. 上传本地成品

优先从主页实际显示的 Magic Layers / AI可编辑图层 / AI图层 / 魔法图层 / 魔术图层入口进入，点击 Select Media / 选择媒体等按钮上传图片。上传后如果显示媒体列表，点击对应缩略图的“选择此图片并编辑”，再进入编辑器处理。若进入的是“剪裁”面板，保持原始比例点击“完成”，然后选择“编辑 → AI图层”。也可打开新设计，在“上传”中导入本地图片，加入画布并选中，再从图片编辑工具寻找 Magic Layers。

需要从本地补传时，走网页的文件选择器：若工具提供文档化的文件上传接口就使用；否则操作原生选择窗口。macOS 选择窗口可用 Command+Shift+G 打开“前往文件夹”，粘贴文件绝对路径、确认，再点击“打开”。每个动作后读取新状态，确认选择了正确文件。

不要用 FileBatchUpload 的短链中转，不需要把照片部署到公共图床。只上传本次成品，不连带上传整份工作目录。

确认上传缩略图与原图一致，画布比例正确。设计标题使用 `Daily Collage - <主题>`。保存实际地址栏中的设计 URL；没有产生设计 URL 时保持 null，不能猜测。

## 4. 执行 Magic Layers

1. 在实际页面定位 Magic Layers，不能把背景移除、Magic Grab 或普通“图层”面板当作拆层功能。
2. 读取页面说明、可用额度和运行按钮。已授权本次处理时直接运行；若要求额外购买或升级，记录权益阻塞，不自行购买。
3. 有些版本点击“AI图层”就开始处理，不另弹运行确认框。看到画布扫描动画或进度后记录 `processing`，通过页面状态检查结果，避免连续点击。异步处理中每隔约 15–30 秒观察，持续向用户报告有意义进度。
4. 约 5 分钟仍无结果则保留 `processing` 与页面链接，说明仍在处理中；不把超时等同失败。出现明确错误先记录原文，修复明确原因后至多重试一次。
5. 找不到入口时，检查主页与选中图片后的编辑面板，并参考当前官方帮助。仍没有则记录 `feature_unavailable` 和站点/页面观察，不宣称所有 Canva 账号都不支持，不静默改用其他产品。

## 5. 验证、保存、交付

- 等待处理完成并进入编辑器；出现一个全图边框只能证明图片可选中。
- 若结果被组合，进入组合内部或在合适时取消组合。检查“位置/图层”等面板，分别选中至少两个不同视觉元素（例如人物与钥匙），确认各自有独立选框。
- 必要时将一个装饰物轻移一次并立即撤销，检查其他元素没有随之移动。不要为验证破坏最终构图。
- 与原 PNG 对照人物面部、主体完整性、文字（若存在）、装饰物和背景，说明可见的 AI 重建差异。乐谱、手写信等纸张纹理可能被误识别成大量重复文本框；发现后明确报告，不能以图层数量多判断还原质量。不能承诺每张素材都被准确还原。
- 等待网页保存状态完成，记录 `layers_verified`、设计链接及具体验证证据。若只能确认上传，则保持 `uploaded`。
- 最终交付原 PNG、本次设计链接、拆层验证结论；不必修改公开分享权限，不发布到社交平台。若阻塞，明确已完成到哪一步、用户需要做什么、从哪个链接或文件续跑。
